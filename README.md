# BudgetBuddy

BudgetBuddy is a full-stack budget tracking application built to demonstrate practical software engineering and DevOps concepts in a clean, portfolio-friendly format. The repository combines a modern user interface, a REST API, and supporting infrastructure code in a single project.

## Technology Stack

### Application
- React.js
- Tailwind CSS
- Node.js
- Express.js
- MongoDB
- JWT authentication

### Delivery and Infrastructure
- Docker
- Docker Compose
- Kubernetes
- Terraform
- Ansible
- Jenkins
- Git and GitHub

## Overview

The project is organized as a frontend, backend, and infrastructure workspace. It is designed to show how a modern application can be developed, containerized, and managed with common industry tools while keeping the repository structured and easy to understand.
